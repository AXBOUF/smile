# 😊 Smile Earn

**Smile Earn** is a starter full-stack project that shows how **face recognition can be used as a loyalty system**.

Your face acts as your loyalty card — scan, identify, earn points.

This repo is meant for **learning and experimentation**, not production use.

---

## 💡 What This Project Does

- Register users using face images
- Recognize faces using face encodings
- Simulate a loyalty system (no real DB yet)
- Simple Flask backend with HTML/CSS frontend

---

## 🚧 Important Note

- Uses local files (`db.json`, image folders, pickle files)
- No real database yet
- Built as a **base project to extend**

---

## 🗂 Key Tech

- Python + Flask
- OpenCV / face_recognition
- HTML & CSS
